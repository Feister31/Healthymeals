🔗 Connect to Airtable (Optional)

Connect your Airtable base to sync recipes, meal plans, and restaurants

How to get Airtable credentials:

  1. Go to airtable.com/account
  2. Under "API", click "Generate API key"
  3. Copy your API key
  4. Go to your base → Help → API documentation
  5. Copy the Base ID from the URL (starts with "app...")
  6. Paste both here and click Connect!
